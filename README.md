# Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes sales data using Python and Power BI to identify sales trends, product performance, category performance, and regional performance.

The project includes data cleaning and exploratory data analysis using Python, followed by an interactive dashboard developed in Power BI.

📈 Power BI Dashboard

The Power BI dashboard contains four main analytical pages:

1. Sales Overview

Provides an overall view of sales performance with KPIs, filters, monthly sales trends, and product/category analysis.

2. Product & Category

Analyzes sales performance across products and categories using bar charts, donut charts, and a detailed table.

3. Regional Analysis

Compares sales and quantity performance across different regions.

4. Time & Performance

Analyzes monthly sales performance and sales trends over time.
